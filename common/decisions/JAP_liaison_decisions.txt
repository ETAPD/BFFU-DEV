# Imperial Liaison Conference - Army/Navy interservice rivalry (Hearts of Oak's
# JAP_interservice_rivalry category, adapted - not copied). One liaison action may
# be taken per 120 days (shared JAP_liaison_cd cooldown). Each tilts the
# JAP_liaison_* spirit ladder toward the Army or Navy and grants a matching bonus.
# Paired Army/Navy variants sit next to each other. No decision carries a
# temporary "120-day" modifier - every substantial pair instead grants a
# PERMANENT hidden technology (Oak's set_technology method; see the "Imperial
# Liaison Conference" header in JAP_army_custom_techs.txt for the tech defs,
# each designed to fit its own decision rather than reusing Oak's exact stats).
# Unlocked by "Begin the Imperial Liaison Conferences".

		icon = GFX_decision_generic_army

		available = {
			NOT = { has_country_flag = JAP_liaison_cd }
			NOT = { has_idea = JAP_liaison_army_dominant }

		complete_effect = {
			JAP_liaison_towards_army = yes
