###########################################################################
# SOUTH AFRICA
#
# Design: the 1930s Union is an economic and political hole. Entering the
# war in September 1939 is what lifts the economy out of the Depression -
# the SAF_south_african_economy panel is never removed, it is upgraded, and
# it runs from Depression-era negatives to genuine wartime prosperity.
#
# Two democratic TEMPOS, not ideologies:
#   Hertzog (Fusion/neutrality) buys Afrikaner acquiescence with the
#     segregation bills; cheap politics, slow industry, an army that will
#     not fight.
#   Smuts  (splits the United Party) rearms and industrialises; eats the
#     stability and Afrikaner cost he refused to pay.
# Both converge on SAF_the_september_1939_vote. The Hertzog player LOSES
# that vote - the motion falls 80-67, Hertzog resigns, Smuts is installed
# over him - and inherits Smuts's Afrikaner problem. That is the point.
#
# LAYOUT: x = 0..40. The shared Commonwealth tree sits at x = 45 for SAF
# (commonwealth_shared.txt gives SAF offset x = -5 against x = 50).
# Nothing here may exceed x = 40.
#     x=1..3   INDUSTRY
#     x=5..19  POLITICAL (Hertzog 5..11 | Smuts 13..19)
#     x=9..15  WARTIME TAIL (below the vote at x=12)
#     x=20..30 ARMY
#     x=31..35 AIR
#     x=36..40 NAVY
#
# FROZEN IDS - renaming these silently breaks other files:
#   SAF_king_of_the_desert  / SAF_queen_of_the_desert
#     -> read by SAF_organization.txt as has_completed_focus gates.
#   mio:SAF_iscor_organization / mio:SAF_cope_organization
#     -> read by commonwealth_shared.txt:402,582.
#
# SPAWN-IN RULES (enforced): factories, building slots and research slots
# only. No equipment, no divisions, no manpower. Exactly one division
# template (SAF_the_coastal_garrison_scheme), shipped locked.
# ahead_reduction and complete_mio_trait appear ONLY in the army tree.
###########################################################################
