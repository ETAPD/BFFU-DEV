# ger_tiger2_henschel — traced from a non-free drawing

Source: the-blueprints.com, "Sd.Kfz. 182 Pz.Kpfw.VI Ausf.B King Tiger (Henschel Turret)" four-view (ID 63811, source
Dr Dan Saranga), public 500 px preview:
https://www.the-blueprints.com/blueprints/tanks/ww2-tanks-germany-2/63811/view/sdkfz_182_pzkpfwvi_ausfb_king_tiger_henschel_turret/

No free-licence Tiger II four-view exists (see VARIANTS.md), so with the project owner's agreement this commercial
drawing is used only as private tracing reference, as for the Panzer III and Panther. The sheet, crops and drawing
overlays live in the git-ignored `reference/blueprints_nonfree/ger_tiger2_henschel/`. To check the model, download the
preview again, crop and resample it as the spec docstring says (each view calibrated on its own against the
documented 7.38 m / 10.286 m / 3.755 m / 3.09 m) and run overlay_render.py on it.

`outline_{side,top,front,rear}.png` here are the model's own line renders at 175 px/m in those views (no drawing).
`photos/` holds the free-licence museum and wartime photos checked (credits in `photos/CREDITS.md`).
