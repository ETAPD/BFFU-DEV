# ger_panther_g — traced from a non-free drawing

Source: the-blueprints.com, "Sd.Kfz. 171 Pz.Kpfw.V Ausf.G Panther" four-view (ID 72512, source Dr Dan Saranga),
public 500 px preview: https://www.the-blueprints.com/blueprints/tanks/ww2-tanks-germany-2/72512/view/sd_kfz_171_pzkpfw_v_ausfg_panther/

No free-licence four-view of any Panther exists (see VARIANTS.md), so with the project owner's agreement this
commercial drawing is used only as private tracing reference, as for the Panzer III. The sheet, crops, calibration
grids and drawing overlays live in the git-ignored `reference/blueprints_nonfree/ger_panther_g/`. To check the model,
download the preview again, crop and resample it as the spec docstring says (each view calibrated on its own against
the documented 6.87 m / 8.66 m / 3.27 m / 2.99 m) and run overlay_render.py on it.

`outline_{side,top,front,rear}.png` here are the model's own line renders at 175 px/m in those views (no drawing).
`photos/` holds the free-licence museum and wartime photos checked (credits in `photos/CREDITS.md`).
