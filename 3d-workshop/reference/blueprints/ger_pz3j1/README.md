# ger_pz3j1 — traced from a non-free drawing

Source: the-blueprints.com, "Sd.Kfz. 141 PzKpfw III Ausf. J" four-view (https://www.the-blueprints.com/blueprints/tanks/ww2-tanks-germany-2/81818/view/sd_kfz_141_pzkpfwiii_ausfj/), used for the J1's differences from the Ausf. L geometry.

That drawing is commercial, so it is used only as private tracing reference (agreed with the project owner) and is
not in the repository: the crops, calibration and the drawing overlays live in the git-ignored
`reference/blueprints_nonfree/ger_pz3j1/`. To check the model, download the drawing again, crop and resample it as the
spec docstring says, and run overlay_render.py on it. `outline_{side,top,front,rear}.png` here are the model's own
line renders at 175 px/m in those views (no drawing).
