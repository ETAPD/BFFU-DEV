# ger_tiger1_mid — drawing

Traced from the public-domain Tiger 131 four-view of `ger_tiger1_early` (School of Tank Technology, January 1944;
the calibrated `side/top/front/rear.png` live in `../ger_tiger1_early/`). Hull, running gear, turret shell, mantlet and
gun are shared with that drawing; the photos in `photos/` confirm they are unchanged on the mid-production Tiger.
The differences (cast cupola, no Feifel filters, no smoke dischargers, Zimmerit) are set from the photos and the
documented production changes (spec docstring). `overlay_*.png` are the mid model's outlines over that drawing: the
red lines that leave the drawing are exactly those differences.
