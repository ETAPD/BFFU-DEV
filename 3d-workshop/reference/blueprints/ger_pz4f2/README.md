# Pz IV Ausf. F2 — no drawing of its own

The F2 and the early Ausf. G are one vehicle (renamed in July 1942), so `ger_pz4f2` uses the early-G geometry traced
from `../ger_pz4g/` (MasterJVN, "PzIV-012-G-Variantes.jpg", CC BY 4.0). These overlays are the F2 spec on that
drawing (crops and datums as in `ger_pz4g`).
