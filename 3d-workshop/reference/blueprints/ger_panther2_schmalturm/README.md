# ger_panther2_schmalturm — traced from non-free colour profiles

Sources: the-blueprints.com Panther II sheets by Dr Dan Saranga, public 500 px previews:
- ID 31013 (side): https://www.the-blueprints.com/blueprints/tanks/ww2-tanks-germany-2/31013/view/sdkfz_171_pzkpfw_v_panther_ii/
- ID 31012 (side, front, rear): https://www.the-blueprints.com/blueprints/tanks/ww2-tanks-germany-2/31012/view/sdkfz_171_pzkpfw_v_panther_ii/
- ID 15894 (four-view, top used): https://www.the-blueprints.com/blueprints/tanks/ww2-tanks-germany-2/15894/view/sdkfz_171_panther_ii_pzkpfwv/

No line drawing of the Panther II exists; these are shaded colour profiles, used with the project owner's agreement
as private tracing reference only (as the Pz III and Panther sheets). They show the planned Panther II with the
Schmalturm. The sheets, crops and drawing overlays live in the git-ignored `reference/blueprints_nonfree/ger_panther2_schmalturm/`;
calibration and datums are in the spec docstring.

`outline_{side,top,front,rear}.png` here are the model's own line renders at 175 px/m in those views (no drawing).
No photos exist of this configuration; the hull is checked against the prototype's photos in `../ger_panther2/photos/`.
