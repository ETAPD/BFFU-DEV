# ger_pz3f — traced from a non-free drawing

Source: the-blueprints.com four-view "PzKpfw III Ausf. F mit 5 cm KwK 38" (https://www.the-blueprints.com/blueprints/tanks/ww2-tanks-germany-1/35145/view/pzkpfw_iii_ausf_f_mit_5_cm_kwk_38/); the 3.7 cm gun and internal mantlet from the Ausf. C side view (ger_pz3c).

That drawing is commercial, so it is used only as private tracing reference (agreed with the project owner) and is
not in the repository: the crops, calibration and the drawing overlays live in the git-ignored
`reference/blueprints_nonfree/ger_pz3f/`. To check the model, download the drawing again, crop and resample it as the
spec docstring says, and run overlay_render.py on it. `outline_{side,top,front,rear}.png` here are the model's own
line renders at 175 px/m in those views (no drawing).
