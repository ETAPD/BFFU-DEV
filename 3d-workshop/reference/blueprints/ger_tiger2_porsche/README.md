# ger_tiger2_porsche — traced from non-free drawings

Turret: the-blueprints.com, "Sd.Kfz. 182 Tiger II Pz.Kpfw. VI King Tiger Ausf.B" four-view with the Porsche turret
(ID 14674, source Dr Dan Saranga), public 500 px preview:
https://the-blueprints.com/blueprints/tanks/ww2-tanks-germany-2/14674/view/sdkfz_182_tiger_ii_pzkpfw_vi_king_tiger_ausfb
Hull and running gear: the Henschel-turret sheet of `ger_tiger2_henschel` (ID 63811); the hull lines of sheet 14674
lie on it within a sheet pixel.

Used with the project owner's agreement as private tracing reference only (as the Panzer III and Panther): sheets,
crops and drawing overlays live in the git-ignored `reference/blueprints_nonfree/ger_tiger2_porsche/` (calibration in
the spec docstring). `outline_{side,top,front,rear}.png` here are the model's own line renders at 175 px/m (no
drawing). `photos/` holds the free-licence photos checked (credits in `photos/CREDITS.md`).
